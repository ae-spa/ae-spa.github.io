PROJECT 02 — SECURITY MONITORING

Wazuh 기반 엔드포인트 모니터링 랩

Windows 엔드포인트 이벤트 수집과 모니터링을 위한 개인 가상 실습 환경입니다.

PERIOD진행 중인 개인 프로젝트
ROLE / ENVIRONMENTVMware · Ubuntu Server · Windows 11
TOOLSWazuh Manager / Agent · Sysmon

01. 프로젝트 개요

Ubuntu 기반 Wazuh Manager를 구성하고 Windows 11 에이전트를 등록해 연결을 확인했습니다.

02. 수행 내용 및 분석

Sysmon 이벤트를 생성하고 Wazuh 대시보드에서 프로세스 생성·종료 이벤트가 수집되는 것을 확인했습니다. 탐지 규칙 검증과 알림 연동은 완료 후 추가할 예정입니다.

공개 전 본인 기여 범위와 실제 검증 결과를 확인하고, 내부 IP·기관 식별 정보·민감한 증거 데이터는 제외하거나 마스킹하세요.
