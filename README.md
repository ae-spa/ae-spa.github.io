# Security Analyst Portfolio starter

한국어 보안 분석 포트폴리오 초안입니다. HTML/CSS/JavaScript만 사용하므로 별도 빌드 과정 없이 GitHub Pages에 배포할 수 있습니다.

## 파일 구조
- `index.html`: 메인 페이지 콘텐츠
- `assets/style.css`: 디자인 및 반응형 레이아웃
- `assets/script.js`: 모바일 메뉴 등 간단한 동작
- `projects/`: 이후 프로젝트 상세 페이지를 추가할 위치

## 먼저 수정할 내용
1. `YOUR NAME`을 공개할 이름 또는 영문 이니셜로 변경
2. `YOUR_EMAIL@example.com`을 실제 연락 이메일로 변경
3. `YOUR_GITHUB`를 GitHub 사용자명으로 변경
4. 프로젝트 설명과 사용 도구를 실제 본인 담당 범위에 맞게 검토
5. 상세 페이지 링크는 각 페이지를 작성한 뒤 활성화

## GitHub Pages 배포
1. GitHub에서 `사용자명.github.io`라는 이름의 Public Repository 생성
2. 이 폴더 안의 파일을 Repository 최상위에 업로드
3. Repository의 Settings → Pages 이동
4. Build and deployment에서 Deploy from a branch 선택
5. Branch는 `main`, 폴더는 `/ (root)`로 설정 후 Save
6. 배포가 완료되면 `https://사용자명.github.io`에서 확인

GitHub Pages 사이트는 공개 웹사이트입니다. 병원/기업/실습 환경의 실제 식별 정보, 내부 IP, 계정, 로그 원본, 미공개 보고서 등은 공개하지 마세요.
